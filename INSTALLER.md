# Создание установщика NOVA

> Сценарий подготовлен, но его сборка и запуск на Windows пока не проверены. Для установки и запуска NOVA отдельно необходимы .NET 10 Desktop Runtime x64 и WebView2 Runtime.

1. Установите [Inno Setup 6](https://jrsoftware.org/isdl.php).
2. Распакуйте опубликованную Windows-сборку целиком в папку `packaging/app/` рядом с `packaging/NOVA-setup.iss`. Внутри `app` должны находиться `Nova.App.exe` и все сопровождающие файлы, а не ещё одна вложенная папка с ними.
3. Откройте `packaging/NOVA-setup.iss` в Inno Setup и выберите **Build → Compile**.
4. Полученный `NOVA-Setup.exe` появится в `packaging/Output/`. Протестируйте установку, ярлыки, запуск и удаление на тестовой Windows до публикации.

Сценарий устанавливает файлы в `%LOCALAPPDATA%\Programs\NOVA` без администратора и не скачивает зависимости. Перед обновлением полностью завершите NOVA из трея. Данные `%LOCALAPPDATA%\NOVA` и исходные файлы обоев скрипт не удаляет.

Либо соберите приложение командой из README, затем скопируйте **содержимое** папки `publish` в `packaging/app/`. Перед распространением проверьте лицензии зависимостей и условия собственного кода.

# NOVA — живые обои для Windows

> **Состояние: экспериментальный исходный проект, не проверенный на Windows.** Код WPF кросс-компилирован в Linux с .NET SDK 10.0.404; тесты разбора проектов прошли. Реальные окна, видео, WebView2, значки рабочего стола, монитор и Wallpaper Engine не запускались и могут потребовать исправлений на конкретной системе. Это не подтверждённый готовый релиз; см. ограничения и чек-лист. Никакие файлы конкретных обоев пользователя, кроме изображения дизайн-системы, не были предоставлены.

## Сборка и запуск

1. Windows 10/11 x64, актуальный .NET 10 SDK и доступ к NuGet при первой сборке. Нужны **.NET Desktop Runtime 10 x64** при запуске framework-dependent приложения и **Microsoft Edge WebView2 Runtime** (Evergreen x64; часто уже установлен): https://developer.microsoft.com/microsoft-edge/webview2/ .
2. Для сборки двойным щелчком запустите `build.bat` в корне распакованного **исходного проекта**. Скрипт проверит наличие .NET 10 SDK и соберёт `publish\Nova.App.exe`; при первой сборке нужен интернет для NuGet. После сборки он предложит запустить приложение. Окно со сборкой показывает ошибки и не закрывается автоматически.
3. Или выполните в PowerShell в корне проекта:

```powershell
dotnet restore NOVA.sln
dotnet build NOVA.sln -c Release
dotnet run --project Nova.App\Nova.App.csproj -c Release
# или публикация с запуском EXE:
dotnet publish Nova.App\Nova.App.csproj -c Release -r win-x64 --self-contained false -o publish
.\publish\Nova.App.exe
```

Можно собрать из Visual Studio с workload «Разработка классических приложений .NET», используя SDK .NET 10 и платформу x64. Для автозапуска используйте опубликованный EXE, а не `dotnet run`. Публикация выводит много файлов, в том числе VLC; не перемещайте один EXE отдельно. Администратор не требуется. Для автономного .NET Runtime можно собрать `--self-contained true`, но WebView2 Runtime всё равно необходим. Ничего не скачивается из Steam.

**Готовая публикация, если предоставлена отдельно:** распакуйте весь архив, установите Desktop Runtime и WebView2 Runtime, запустите Nova.App.exe. Это лишь кросс-собранный бинарный комплект, а не проверенный установщик. Перед распространением проверьте лицензии и исходный код зависимостей (см. `licenses/NOTICE.txt`).

## Как пользоваться

- «Обои» → «Добавить обои» → «Выбрать файл» — выбрать MP4, WebM, GIF, HTML или `project.json`; «Выбрать папку» — выбрать папку с `index.html` или `project.json`. Папка без этих файлов предлагает поиск проектов в подпапках (до 10 000, глубина 16, без перехода по точкам повторной обработки).
- Для Workshop выберите вручную уже установленную папку `steamapps\workshop\content\431960` или папку одного проекта. JSON читается локально, оригиналы не изменяются. Пустое или испорченное описание вызывает ошибку. Дубликат по абсолютному пути не добавляется.
- В «Библиотеке» выберите карточку; внизу показаны тип, совместимость и путь. Выберите монитор Windows и нажмите «Применить». При отсутствии файла используйте «Указать путь заново». «Удалить из библиотеки» удаляет только запись. Обложка берётся из поля `preview`, если оно есть; при отсутствии можно запросить миниатюру видео вручную или с разрешения включить автоматическое создание в настройках. Если изображение недоступно или не поддерживается, карточка и главный экран показывают заглушку. Большое изображение — статическая обложка, не живой поток. Демонстрационный `Demo/index.html` добавляется автоматически со своей обложкой и работает локально, не требуя сети.
- Для сцен установите и **запустите** Wallpaper Engine. В настройках выберите `wallpaper32.exe` или `wallpaper64.exe`, укажите индекс его монитора (нумерация с 0) и сохраните. Выберите сцену и подтвердите замену обоев на указанном мониторе; после подтверждения NOVA останавливает свои обои на всех мониторах и при успешной отправке команды очищает сохранённые назначения NOVA. Индекс WE может отличаться от порядка мониторов Windows: проверьте его в настройках самого WE. Отправляется документированная команда `-control openWallpaper -file <project.json> -monitor <index>`. Подтверждение исполнения/статуса от WE не доступно. Никакие глобальные команды pause/play/stop ему не отправляются.
- Встроенный движок поддерживает отдельные окна видео/веб-обоев для нескольких мониторов: в библиотеке выберите монитор и примените обои, затем выберите другой и повторите. Замена, пауза и остановка действуют только на выбранный монитор. Назначения сохраняются отдельно, а прежняя настройка одного монитора переносится автоматически. После полного выхода окна закрываются и назначения остаются для восстановления; «Остановить» удаляет назначение выбранного монитора. После смены конфигурации мониторов все собственные окна безопасно закрываются, назначения сохраняются и обои нужно повторно применить; после перезапуска восстанавливаются только подключённые экраны. Отображение и восстановление на реальных нескольких мониторах ещё не проверены на Windows. Громкость и сетевое разрешение общие, а независимые движки потребляют больше ресурсов.
- В настройках можно отдельно включить или выключить декоративные снег и мерцающую гирлянду в окне NOVA (изменение видно сразу; для сохранения нажмите «Сохранить настройки»). Эти эффекты не добавляются на рабочий стол и при скрытии окна не анимируются. Также можно включить автозапуск, автоматическую паузу при блокировке и полноэкранном приложении, звук видео, разрешить веб-обоям сеть и указать WE. Параметры сети вступают в силу при повторном применении обоев. Для WebView2 уровень громкости не задаётся: 0 выключает звук, любое другое значение включает его.

## Избранное, темы и миниатюры видео

- В библиотеке нажмите звёздочку на карточке, чтобы добавить или убрать обои из избранного. Флажок «Показывать только избранное» работает одновременно с поиском и фильтром типа. Отметка сохраняется в библиотеке и при указании пути заново. Удаление из библиотеки не удаляет исходники.
- В настройках выберите оранжевый, голубой, фиолетовый или мятный акцент и насыщенность 50–100%. Тёмная основа сохраняется. Акцент, активная навигация, основные кнопки, отметки и часть подписей меняются сразу; декоративная обложка демо и эффекты не перекрашиваются. Выбор сохраняется сразу.
- Для видео без существующей обложки выберите карточку и нажмите **«Создать миниатюру видео»**. Можно разрешить **«Создавать миниатюры видео без обложек автоматически»** в настройках: NOVA последовательно проверит имеющуюся библиотеку и добавляемые записи. По умолчанию автоматический режим выключен. Он работает только когда чтение настроек прошло успешно; выключение останавливает очередь, но не может немедленно прервать уже запущенный обработчик.
- Для получения кадра NOVA обращается к механизму миниатюр Windows в фоновом потоке; Windows может использовать установленные системные или сторонние обработчики и кодеки. NOVA не запускает собственные сторонние EXE или установщики. Результат и выбранный кадр зависят от Windows, установленных кодеков и файла: для некоторых MP4, WebM или GIF миниатюра может не получиться. После ожидания около 20 секунд выдаётся ошибка либо автоматическая очередь останавливается; зависший обработчик Windows может продолжить работу в фоне. Лишь существующие видео на локальных или съёмных дисках допускаются; UNC и подключённые сетевые диски исключены. Синхронизируемые облачные папки и ссылки могут иметь собственные правила загрузки.
- PNG сохраняется отдельно в `%LOCALAPPDATA%\NOVA\thumbnails` и связывается с записью, существующая обложка не перезаписывается. Исходное видео и файлы проекта не меняются. При удалении записи или повторном указании пути созданные PNG не удаляются автоматически; ненужные файлы можно удалить вручную, предварительно проверив, что они не используются. Если PNG удалить, вместо него будет заглушка или, при разрешённом автоматическом режиме, миниатюра будет создана заново при следующей обработке.

## Интерфейс и предпросмотр

- Кнопка внизу бокового меню сворачивает или разворачивает его; иконки остаются доступны и имеют подсказки. Выбор сохраняется.
- На главной странице показаны обложка, состояние и выбранный монитор; «Сменить» открывает библиотеку, «Пауза» и «Остановить» управляют собственными обоями NOVA только на выбранном мониторе. Если окно закрыто, но назначение сохранено, «Забыть назначение» удаляет его. Панель состояния показывает число запущенных окон и сезонный эффект; это не подтверждение видимости картинки в Explorer. Сцены Wallpaper Engine управляются в самом Wallpaper Engine. Команда запуска не является подтверждением фактического вывода картинки — проверьте рабочий стол.
- В «Эффектах» маленький анимированный образец показывает выбранный сезон, интенсивность и скорость **без включения слоя рабочего стола**. Он работает только пока раздел видим; это демонстрация, не гарантия работы оверлея в Windows.
- В настройках переключатель «Плавные переходы и подсветка при наведении» сразу включает или выключает анимацию страниц, кнопок, карточек, темы и добавления в избранное. Режим доступности увеличивает элементы примерно на 12%, повышает контраст подсказок и временно выключает эти переходы, снег и гирлянду в окне, предпросмотр частиц и сезонный эффект рабочего стола. Сохранённые настройки эффектов не теряются: при выключении режима NOVA пытается восстановить ранее включённый эффект. Видео- и веб-обои режим доступности не приостанавливает; веб-анимации и контент управляются самими обоями.
- Успешные действия показываются коротким уведомлением; некоторые ошибки остаются на экране до закрытия и предлагают повтор или открытие существующего диагностического журнала. Повтор обоев требует, чтобы исходный элемент и монитор не были изменены; предупреждения безопасности показываются снова. Журнал может содержать личные пути.

## Трей, история и библиотека

- Правый клик по фирменному значку NOVA открывает тёмное меню: выбор монитора, пауза или продолжение его обоев, сезонный эффект, избранные и недавние обои, открытие библиотеки и выход. При выборе обоев из меню применяются те же предупреждения безопасности и проверки конфликтов, что и в основном окне. Для сцен Wallpaper Engine используется заданный в настройках индекс WE, а не выбор Windows в трее; команда требует отдельного подтверждения.
- В истории хранится до 12 разных последних записей, команда может не означать, что картинка действительно отобразилась. Главный экран и меню трея показывают до 8 недавних записей. На главной нажмите на запись, чтобы выбрать её в библиотеке; из трея её можно применить непосредственно к выбранному монитору. Удаление записи удаляет её из истории, но не исходный файл.
- В библиотеке переключайте **крупные карточки**, **компактные карточки** и **список**; выбранный вид сохраняется. При наведении или клавиатурном фокусе карточка показывает название и тип на обложке. Звезда по-прежнему управляет избранным.

## Совместимость

| Тип | Механизм | Ограничения |
|---|---|---|
| MP4 / WebM | Встроенный LibVLC | Кодеки, декодирование, зацикливание и воспроизведение не проверены на Windows. |
| GIF | Импорт в VLC как медиа | Анимация и цикл зависят от поддержки конкретного GIF в сборке VLC; **не подтверждены**. |
| Локальный HTML и проекты WE Web | WebView2, виртуальный домен корня проекта | Не полная совместимость. Начальные `general.properties` передаются в `applyUserProperties`, событие `setPaused` передаётся. Настройка свойств через UI, аудиоанализ, взаимодействие с мышью, пользовательские каталоги, прочие WE API и плагины не реализованы. |
| WE Scene / `scene.pkg` | Через отдельно установленный и запущенный WE | Автономного движка нет. Команда открывает проект и заменяет обои на выбранном мониторе WE, статус не проверяется. |
| WE Application | Не поддерживается | Не запускается ни автоматически, ни через WE из NOVA. |
| Другие / неизвестные | Импорт метаданных, если допустим | Не воспроизводятся. |

Веб-пауза **частичная**: отправляется `setPaused`, останавливаются CSS-анимации и элементы audio/video, но произвольный JavaScript, canvas и сетевые запросы могут продолжать работу. Собственное демо поддерживает `setPaused`. Видео-пауза использует VLC. Автопауза определяет полноэкранность по размеру активного окна каждые 2 секунды; это эвристика, которая может ошибаться на пограничных окнах и не управляет внешним WE. Ограничение FPS и режимы fit/fill не реализованы и не выдаются за работающие. Запуск WE при работе NOVA может создать конфликт; приложение предупреждает, но не умеет надёжно определять чужие обои на конкретном мониторе.

## Безопасность и данные

Библиотека и настройки: `%LOCALAPPDATA%\NOVA\state.json`; кэш WebView2 — рядом. Ошибка чтения данных не приводит к перезаписи исходного файла: сохранение отключается на текущий запуск. `project.json` используется только для чтения, относительные пути `file` и `preview` проверяются на выход из корня и точки повторной обработки в существующих компонентах. Поиск папок не обходит reparse points. Интернет по умолчанию блокируется фильтром запросов WebView2; доступ можно включить глобально для веб-обоев. Новые окна, загрузки и запрошенные разрешения блокируются. Это **не абсолютная песочница** и не гарантия изоляции протоколов, дочерних ресурсов и символических ссылок проекта; вредоносные локальные веб-проекты не запускайте. Адреса страниц ограничены виртуальным доменом, но содержимое может выполнять JavaScript. Не используйте неподтверждённые/чужие файлы. DRM, загрузку платного контента и авторизацию Steam приложение не обходит.

## Сезонные эффекты на рабочем столе

Откройте **«Эффекты» → «Включить эффект»** и выберите снег, осенние листья, дождь или цветочные лепестки. Ползунки интенсивности и скорости от 25 до 200% действуют на выбранный эффект и сохраняются автоматически; число частиц ограничено для снижения нагрузки. Это отдельный прозрачный слой поверх рабочей области мониторов и обычных окон; он не меняет обои. Частицы настроены на пропуск кликов, панель задач исключается, если Windows резервирует её область. Эффект по умолчанию выключен; его настройки и состояние сохраняются. Команда включения/выключения есть в трее. При полном выходе слои исчезают; при следующем запуске ранее включённый эффект восстанавливается. Отдельный снег внутри окна NOVA настраивается в общих настройках и этими ползунками не управляется.

Опция **«Сугробы на окнах»** работает только для снега и создаёт отдельные перетаскиваемые снежные шапки на обычных видимых окнах: зажмите сугроб и переместите мышью вдоль окна. Положение запоминается на время жизни окна и сеанса NOVA. Для снижения нагрузки показывается не более 10 сугробов, перекрытые и некоторые бесрамочные, скрытые или полноэкранные окна пропускаются. Сугроб намеренно перехватывает мышь в пределах своей формы, поэтому не размещайте его поверх важных кнопок. Если он мешает, передвиньте его, выключите сугробы или весь снег через NOVA/трей.

Эффект скрывается при блокировке и пытается скрываться на мониторе полноэкранного приложения; это эвристика и она может ошибаться. Положение, многомониторный режим и DPI, UAC/защищённый рабочий стол, а также совместимость с играми и другими оверлеями **не проверены на Windows**. Мгновенное перемещение окна может сопровождаться задержкой до следующего обновления. Если слой мешает, полностью выйдите из NOVA из трея.

## Набор курсоров Windows

В разделе **«Курсор»** выберите роль и локальный файл `.cur` или `.ani`, повторите для остальных ролей, наведите указатель на область предпросмотра и нажмите «Применить набор». Доступны обычная стрелка (Arrow), текст (IBeam), ожидание (Wait), работа в фоне (AppStarting) и ссылка (Hand). Пропущенные роли не изменяются. Файлы можно выбрать вручную с любыми именами или импортировать из одной папки с точными именами ролей, например `Arrow.cur`, `Hand.ani`; неоднозначные совпадения отклоняются. INF, EXE и установщики не запускаются и файлы схем `.theme` не импортируются. Перед применением NOVA запросит подтверждение и проверит все выбранные файлы через Windows; для каждого изменяемого указателя сохраняется исходное значение. Настройка сохраняется после выхода, не удаляйте и не перемещайте файлы, пока они используются.

«Вернуть прежние» восстанавливает все роли, изменённые через NOVA. Резервная копия `%LOCALAPPDATA%\NOVA\cursor-arrow-backup.json` сохраняется до изменений; прежняя копия от версии с одной стрелкой также поддерживается. Если хотя бы одна из отслеживаемых ролей изменена вне NOVA, применение и восстановление отменяются целиком, чтобы не перезаписать чужой выбор. Резервная копия остаётся на диске. При ошибке NOVA пытается откатить изменения, но аварийное завершение во время записи или неудачный откат могут потребовать ручного восстановления. При проблемах откройте системные параметры мыши → дополнительные параметры указателей и выберите стандартную схему. Применение, восстановление, импорт и предпросмотр не проверены на реальной Windows.

## Панель задач (экспериментально)

Раздел «Панель задач» меняет цвет и непрозрачность **основной** панели Проводника по кнопке «Применить». Эффект временный: NOVA сначала пытается прочитать исходный стиль и ничего не меняет, если это не удалось. Кнопка «Завершить управление» и полный выход пытаются вернуть исходное состояние. Если Проводник или другая программа успели изменить стиль, NOVA не будет перезаписывать их изменения. Стиль не применяется автоматически после перезапуска; реестр Windows не изменяется.

Способ использует недокументированный `SetWindowCompositionAttribute` и зависит от версии Windows. Windows 11 22H2 и новее могут рисовать фон поверх эффекта — успешная отправка команды не подтверждает, что эффект виден. Настройки не внедряются в Проводник, не управляют дополнительными панелями и могут конфликтовать с TranslucentTB и другими утилитами. При сбое или внезапном завершении NOVA внешний вид панели может не вернуться автоматически: используйте «Параметры Windows → Персонализация → Цвета» либо перезапустите Проводник. Кнопка «Открыть цвета Windows» ведёт в системный раздел. Этот функционал не проверен на Windows.

## Если рабочий стол не отображается

NOVA различает классическую схему WorkerW и новый вариант с дочерним WorkerW/Progman в Windows 11 24H2+. Для последнего варианта приложение удерживает стиль WS_EX_LAYERED при обработке сообщения WPF и проверяет его вместе с альфа-каналом и расположением под значками. Исправление кода 87 кросс-собрано, но не проверено на реальной Windows. Размещение зависит от недокументированного устройства Explorer и может не работать в отдельных сборках Windows 10/11, конфигурациях DPI или с другими программами живых обоев. Проверьте WebView2 Runtime, VLC, кодек, наличие файла, подключение выбранного монитора, работу Проводника и выключите другие приложения для обоев. При смене конфигурации мониторов или исчезновении WorkerW NOVA останавливает собственное окно и сообщает об ошибке; повторно примените обои. **Автоматическое восстановление после перезапуска Explorer не реализовано.** Если иконки или рабочий стол ведут себя необычно, выберите «Выход» в трее NOVA; затем при необходимости перезапустите Проводник из диспетчера задач и задайте обычные обои в настройках Windows. NOVA не изменяет статические обои и не удаляет исходники. Диагностика создаётся в `%LOCALAPPDATA%\NOVA\desktop-diagnostics.log` при попытке запуска; сообщения об ошибках могут содержать пути к файлам. Перед отправкой проверьте и при необходимости удалите личную информацию.

## Что проверено

- В этой Linux-среде: `dotnet restore`, `dotnet build NOVA.sln` для `net10.0-windows`, публикация win-x64, тестовый консольный проект `dotnet run --project Nova.Tests`. Проверены импорт видео/веб-папки, распознавание Scene и Application, метаданные веб-проекта, запрет `../` и ошибка некорректного JSON.
- **Не проверено:** запуск WPF на Windows, вывод VLC и WebView2 внутри WorkerW, свойства и пауза реальных WE Web, воспроизведение GIF, видеокодеки, реальные сцены/CLI WE, трей и автозапуск, DPI, независимые обои на нескольких мониторах и восстановление назначений, новое меню трея, виды библиотеки и режим доступности, блокировка и полноэкранные программы, новая схема Progman/WorkerW, экспериментальные эффекты панели задач, перетаскиваемые сугробы, сезонные эффекты, избранное и темы в интерфейсе, создание миниатюр Windows и применение/восстановление наборов курсоров. Cross-compile не подтверждает корректность исполнения.

### Ручной чек-лист на Windows

1. Собрать и открыть приложение на Windows 10 и 11 x64. Проверить масштаб 100%, 150% и изменение размера окна.
2. В библиотеке выбрать «Оранжевая волна · Демо», применить. Убедиться, что анимация видна под значками и значки доступны. Проверить паузу/продолжение/остановку.
3. Импортировать MP4, WebM и GIF отдельно; проверить изображение, звук по умолчанию, цикл, ползунок громкости, паузу и некорректный медиафайл.
4. Перезапустить приложение: библиотека, настройки, монитор и активное назначение должны сохраниться. Закрыть окно, открыть из трея, полностью выйти. Проверьте автозапуск только после включения.
5. Подключить два экрана с разным DPI/разрешением, выбрать второй; проверить физическое расположение и доступность иконок. Отключить его; перезапустить Проводник; проверить сообщение и повторное применение.
6. Переименовать исходный файл; убедиться в ошибке и восстановить путь. Проверить дубликат и повреждённый project.json. Удаление записи не должно трогать файл.
7. Проверить автоматическую паузу на выбранном мониторе при полноэкранной программе и блокировке, а также возобновление. Отдельно проверить частичную паузу веб-проектов.
8. Для легально установленного WE выбрать его EXE, правильный индекс монитора, импортировать локальный Scene, согласиться на замену, проверить факт смены обоев. Повторить без запущенного WE; должен появиться понятный отказ. Оценить совместимость с другими работающими обоями.
9. На вкладке панели задач изменить цвет и прозрачность, проверить эффект на Windows 10/11, нажать «Завершить управление» и проверить восстановление; отдельно проверить, что чужая смена темы не перезаписывается. При необходимости восстановить системную тему в Windows.
10. Проверить веб-проект из доверенного источника без интернета и с разрешённой сетью; настройки применяются после повторного запуска.

## Структура и изменение имени

`Nova.Core` — модели, проверка путей, импорт и хранение; `Nova.App/Services` — WorkerW, VLC/WebView2, CLI и автозапуск; `ViewModel.cs` — состояние интерфейса; WPF XAML и обработчики — представление/поток UI; `Nova.Tests` — автономные тесты без тестового пакета. Архитектура частично MVVM: сложные команды и диалоги пока находятся в code-behind, а не полностью в отдельных ViewModel; это ограничение для дальнейшего расширения. Имя окна и навигации задаётся константой `ViewModel.AppName`; папка данных, ключ автозапуска и демо содержат строку NOVA отдельно — для полного ребрендинга замените и их.

Документация WE: https://help.wallpaperengine.io/en/functionality/cli.html и https://docs.wallpaperengine.io/en/web/api/propertylistener.html . Лицензии и ссылки — `licenses/NOTICE.txt`.

### Дополнительные ручные проверки

- Выбрать каждый сезон, изменить интенсивность и скорость; проверить сохранение и восстановление после перезапуска, а также наличие сугробов только у снега. Включить и выключить эффект через раздел и трей; проверить, что клики и прокрутка проходят к рабочему столу, приложениям и панели задач. Закрыть NOVA полностью — слои исчезают.
- Открыть несколько неперекрывающихся обычных окон; проверить до 10 шапок, перетаскивание, перемещение/минимизацию окон и закрытие, а также скрытие на перекрытых окнах. Сугробы могут захватывать клики на собственной видимой форме.
- Проверить несколько мониторов с разным DPI, блокировку, игру в полноэкранном режиме и изменение конфигурации экранов.
- Выбрать несколько корректных `.cur`/`.ani` для всех пяти ролей, проверить предпросмотр, импорт из папки, частичный набор, применение и восстановление. Повреждённый файл должен отменить применение всего набора. Проверить миграцию старой резервной копии Arrow, а также отказ при внешнем изменении хотя бы одной роли. Проверить восстановление при отсутствии выбранного файла.

### Проверка обновлённого интерфейса на Windows

- Свернуть и развернуть меню; перезапустить программу и проверить сохранение положения. Проверить навигацию с клавиатуры и подсказки.
- Проверить обложку демо, обложки проектов, отсутствие повреждённых изображений, карточки, поиск и фильтры; применить обои, проверить состояние и работу кнопок. Это статические обложки, не живое превью видео.
- Переключить четыре сезона и ползунки, проверить изменение образца без включения desktop-слоя и остановку образца вне страницы.
- Отключить и снова включить анимацию интерфейса, проверить сохранение после перезапуска. Проверить уведомления и кнопку диагностики на реальной ошибке; повтор не должен менять монитор без выбора пользователя.

### Проверка избранного, тем и миниатюр на Windows

- Отметить несколько карточек, включить фильтр избранного, совместить с типом и поиском, снять отметку и перезапустить NOVA. Проверить сохранение отметки при смене пути.
- Переключить четыре цвета и насыщенность; проверить видимость текста, фокуса, карточек и кнопок и сохранение после перезапуска.
- Сначала без автоматического режима создать вручную миниатюру локальных MP4, WebM и GIF без обложки, затем включить автоматический режим и импортировать несколько файлов. Проверить случай неподдерживаемого кодека, файл с уже имеющейся обложкой, отключение очереди, отсутствующий и сетевой файл, обновление карточки и главного экрана. Поддержка зависит от конкретной Windows; самостоятельно эти сценарии в Linux проверить нельзя.

### Проверка новой версии на Windows

- Подключить два монитора, применить разные локальные видео/веб-обои, проверить расположение за значками, отдельно паузу и остановку, выбор мониторa в главном экране и трее, а также восстановление после полного выхода. Проверить замену одних обоев без остановки других, смену DPI, отключение экрана и перезапуск Explorer. Новая работа с несколькими окнами зависит от недокументированного Explorer и в этой среде не проверена.
- Проверить перенос настроек от прошлой версии, список недавних, удаление и перепривязку записи. Проверить вызов избранных/недавних из трея, включая предупреждения безопасности и сцены WE.
- Переключить три вида библиотеки, поиск и избранное, навести мышь и перейти на карточку с клавиатуры; затем проверить увеличение и контраст в режиме доступности, остановку декоративных эффектов и их восстановление после его выключения. Проверить работу при масштабе Windows 100%, 150% и на небольшом экране.

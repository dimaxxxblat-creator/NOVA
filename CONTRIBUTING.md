# Участие в проекте

Спасибо за интерес к NOVA! Проект экспериментальный, а лицензия на собственный код пока не выбрана. Перед отправкой изменений уточните у владельца условия использования и принятия вклада.

## Сообщение об ошибке

1. Проверьте, не описана ли проблема в существующих Issues и в [руководстве](docs/USER_GUIDE.md).
2. Создайте Issue с версией Windows (`Win + R` → `winver`), числом мониторов и масштабом экрана.
3. Укажите шаги воспроизведения, ожидаемый и фактический результат, текст ошибки и снимок экрана, если это безопасно.
4. Для ошибок рабочего стола может помочь `%LOCALAPPDATA%\NOVA\desktop-diagnostics.log`. Проверьте файл на личные пути и другие конфиденциальные данные до отправки.

Не прикрепляйте платные обои, токены, пароли, личные файлы или содержимое чужих проектов без разрешения.

## Разработка и проверка

- Сборка: `dotnet restore NOVA.sln` и `dotnet build NOVA.sln -c Release`.
- Автоматические проверки: `dotnet run --project Nova.Tests/Nova.Tests.csproj -c Release --no-build`.
- Изменения Windows-интерфейса, Explorer, трея, курсоров и воспроизведения требуют отдельной ручной проверки на Windows. Перечислите, что именно проверили и что не смогли проверить.
- Сохраняйте оригинальные файлы обоев, не запускайте исполняемые проекты автоматически и не заявляйте полную совместимость с Wallpaper Engine.

Для предложений откройте Issue с описанием задачи, ожидаемого результата и примерами использования. Для чувствительных проблем безопасности используйте [SECURITY.md](SECURITY.md).

> **Экспериментальный проект.** Исходники кросс-собраны, а автоматические проверки моделей и настроек пройдены в Linux. Запуск и внешний вид на реальной Windows, расположение обоев за значками и работа нескольких мониторов **ещё не проверены**. Пожалуйста, протестируйте проект на своей системе перед повседневным использованием.

## Возможности

| | Возможность | Подробности |
|---|---|---|
| 🖼️ | **Локальная библиотека** | MP4, WebM, GIF, HTML и метаданные локальных проектов Wallpaper Engine; поиск, фильтрация, избранное и три вида карточек. |
| 🖥️ | **Несколько мониторов** | Отдельные назначения видео и веб-обоев, управление и сохранение на каждый монитор. Работа на реальной Windows не подтверждена. |
| 🌧️ | **Сезонные эффекты** | Снег, листья, дождь и лепестки; интенсивность, скорость и экспериментальные перетаскиваемые сугробы. |
| 🎨 | **Персонализация** | Цветовые акценты, насыщенность, декоративные эффекты, режим доступности и отключение анимаций интерфейса. |
| 🖱️ | **Наборы курсоров** | Локальные `.cur` и `.ani` для стрелки, текста, ожидания, работы в фоне и ссылок с возможностью восстановления. |
| ⭐ | **Быстрый доступ** | Избранное, история, тёмное меню трея и автоматические миниатюры видео с разрешения пользователя. |
| ⏸️ | **Управление** | Пауза, автопауза при блокировке или полноэкранном окне, работа в трее и автозапуск. |

Программа старается размещать обои позади значков рабочего стола через слой Explorer; этот механизм недокументирован и зависит от версии Windows. История и статус запуска не доказывают, что изображение действительно появилось на рабочем столе.

## Совместимость

- **Видео / GIF:** встроенный LibVLC. Работа GIF и отдельных кодеков зависит от файла и не подтверждена на Windows.
- **Локальные веб-обои:** WebView2. Поддержка API Wallpaper Engine частичная; произвольный JavaScript может продолжать работу на паузе.
- **Wallpaper Engine Scene:** только через отдельно установленный и запущенный Wallpaper Engine. После подтверждения NOVA остановит свои обои на всех мониторах; состояние внешней сцены не подтверждается.
- **Wallpaper Engine Application:** не запускаются. DRM, Steam и платный контент не обходятся.
- **Панель задач:** экспериментальная настройка, результат зависит от версии Windows и может не отображаться.

## Установка и запуск

Если в разделе **Releases** этого репозитория опубликована сборка, скачайте архив для Windows x64 и распакуйте его целиком. Запустите `Nova.App.exe` из извлечённой папки.

Для запуска необходимы:

1. **Windows 10 или 11 x64**.
2. [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0).
3. [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

Не переносите один `.exe` без остальных файлов. Закрытие окна сворачивает NOVA в трей; для полного выхода выберите **«Выход»** в меню значка. Сборка не включает автоматическую установку компонентов выше.

## Сборка из исходников

Потребуются **.NET 10 SDK** и подключение к NuGet при первом восстановлении пакетов. На Windows можно запустить [`build.bat`](build.bat), либо выполнить в PowerShell из корня репозитория:

```powershell
dotnet restore NOVA.sln
dotnet build NOVA.sln -c Release
dotnet run --project Nova.Tests/Nova.Tests.csproj -c Release --no-build

dotnet publish Nova.App/Nova.App.csproj -c Release -r win-x64 --self-contained false -o publish
.\publish\Nova.App.exe
```

Для создания установщика подготовлен [сценарий Inno Setup](packaging/NOVA-setup.iss) и [инструкция](docs/INSTALLER.md). Сам установщик на Windows пока не проверен и не устанавливает зависимости автоматически.

## Безопасность и данные

- Библиотека и настройки хранятся в `%LOCALAPPDATA%\NOVA`; исходные обои и проекты по умолчанию не удаляются и не изменяются.
- Веб-обои могут выполнять JavaScript. Сеть по умолчанию ограничена, но это **не полноценная песочница**. Используйте только доверенные проекты.
- Автоматические миниатюры выключены по умолчанию: Windows может использовать установленные сторонние обработчики и кодеки.
- Применение курсоров и изменение панели задач затрагивает настройки Windows; функции восстановления имеют ограничения. Сначала ознакомьтесь с [руководством пользователя](docs/USER_GUIDE.md).
- Перед публикацией диагностического журнала удалите личные пути и другую конфиденциальную информацию.
